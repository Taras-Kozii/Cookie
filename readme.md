# Cookie Couture — Landing Page

A modern, responsive website for a premium handmade cookie brand. The project focuses on minimalist design, typography, visual product presentation, and intuitive navigation.

**Live Demo:** [Cookie Couture](https://taras-kozii.github.io/Cookie/)

### Main Technologies

- **HTML5** — semantic and well-structured markup
- **CSS3 / SCSS** — responsive layout, Flexbox, Grid, CSS animations, and transitions
- **JavaScript** — interactive elements and component behavior
- **Responsive Web Design** — optimized for desktop, tablet, and mobile devices
- **Git / GitHub** — version control and deployment via GitHub Pages

### Features

- Responsive layout for different screen sizes
- Modern minimalist UI
- Semantic HTML structure
- Well-organized CSS/SCSS architecture
- Smooth animations and transition effects
- Interactive navigation
- Structured sections for products, locations, careers, catering, and franchise
- Responsive navigation menu and UI components
- Cross-browser compatibility
